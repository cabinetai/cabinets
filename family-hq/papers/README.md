# The drawer

Drop household paperwork here: warranties, insurance documents, school letters,
manuals, receipts for anything that might need returning, photos of paper you'd
otherwise lose. Any format, any name — PDFs, scans, phone photos, emails saved as
files.

No sorting, no folders, no renaming. The Sunday routine reads what's new, pulls out
any dates that matter, and files them on the Board — each one pointing back at the
paper it came from, so the original is one click away when you need it.

Nothing here is ever moved, renamed or deleted.
