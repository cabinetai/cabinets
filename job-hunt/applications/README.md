# One file per application

Copy the example file, rename it (any name is fine — `acme-designer.md` reads well),
and change the answers. Or just tell the clerk in chat — "I applied to Acme for the
designer role" — and it makes the file for you.

The lines the page reads:

- `company:` and `role:` — who and what
- `state:` — one of **Saved · Applied · Interview · Offer · Rejected**, exactly
- `applied:` — the date you applied, `YYYY-MM-DD` (leave empty while it's just Saved)
- `last:` — the date anything last happened, `YYYY-MM-DD`
- `next:` — the next action in plain words ("Follow up Friday if quiet")
- `url:` — the job posting, if you want the page to link to it

Below those lines the file is yours: notes, names, salary numbers, anything. The
clerk writes only under the `## Log` heading, dated, one line per finding — it never
edits your part of the file.
