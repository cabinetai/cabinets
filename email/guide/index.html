01 Apps and Repos
Embed full web apps in the KB — index.html renders as an iframe, an empty .app marker makes it full-screen — and link Git repos with .repo.yaml so agents read source code in context.
 apps repos
02 Symlinks and Load Knowledge
Bring external folders in by direct symlink via Load Knowledge — nothing gets copied; Cabinet writes .cabinet-meta (and .repo.yaml for git repos) into the target folder.
 symlinks knowledge
03 Delegating Between Agents
Dispatch-enabled agents propose work for teammates — LAUNCH_TASK, SCHEDULE_TASK, SCHEDULE_JOB — with every proposal queued for one-click human approval and per-row model/effort overrides.
 agents dispatch
04 Rooms
Switchable workspaces: each room has one big cabinet holding its own files, agents, task board, skills, theme, icon, and color — switch via the sidebar icon or open a room in its own window.
 rooms workspaces
05 Skills
Reusable instruction bundles (SKILL.md plus optional scripts and assets) an agent pulls in per task — where they live, how to install and attach them, and the security model you opt into.
