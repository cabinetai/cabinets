# Drop statements here

Download a statement from your bank or card and put the file in this folder. **CSV**
is best — most banks offer it next to the PDF download — but PDFs work too, and so
does a clear photo of a paper statement.

- More months, better answers. "Recurring" is a pattern, and patterns need history.
  Three months is enough to start; a year is better.
- Several accounts are fine. The audit reads every file here, whatever its name.
- Files are only read. Nothing is edited, moved, deleted — or uploaded anywhere.
- Old statements can stay. The audit works out the months from the contents, not the
  file names.
