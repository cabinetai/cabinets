The workflow — walk, file, fix, sign off
#StepWhoLands in
01 Walk the product
Cold boot → primary flows → empty states → error paths → edge cases → accessibility → performance. Screenshot every friction before fixing anything.
 You screenshots/
02 File every finding
One issue per file, never bundled — severity P0–P4, area code, observation, repro, recommendation.
 You issues/NNN-slug.md
03 Write the walkthrough
The long-form findings page — screenshots inline between issue ranges, top-10 list, themes, and a summary table of every issue.
 You index.md
04 Ship the fixes
The agent takes the next status: open issue — highest severity first — implements it, and appends a Resolution section. One issue per commit.
 Product Senior issues/ + commits
05 Track to done
Every closed issue gets a row in the live tracker; the tally at the top stays canonical against the issue files.
 Product Senior progress.md
06 Build the review
One command — node build-review.mjs — turns the issue files into a paper-themed, click-through slideshow.
 Script review/index.html
07 Stakeholder sign-off
Pass / Fail / comment per issue in the slideshow. Failures loop back into the fix queue as review feedback.
 Reviewer feedback.md

Start from _template/ — the skeleton copies into each dated audit folder; the full method lives in how-to-audit.md.
