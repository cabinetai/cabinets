# How this folder works

Everything in this folder is read before every meal plan. Start by filling in
`what-we-eat.md` — it's a five-minute form in plain sentences.

After that, add a file any time something changes or a plan misses the mark:

- "The kids are off pasta this month."
- "Tuesday dinners need to be 20 minutes, not 40 — swimming ends at 7."
- "That lentil thing from last week — more like that."

One sentence per file or a whole page, either is fine. Plain words beat categories;
write it the way you'd tell a person.
