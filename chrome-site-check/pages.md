# Pages to check

This file is the list. Every morning the routine opens exactly the pages listed at the
bottom of this file, one at a time, and nothing else — it never wanders off into the rest of
your site.

Write each page on its own line, like this: `- Home page — https://yourshop.com/`. That's a
dash, the name you call the page, a long dash, then the address. The name is yours — it's
what you'll see in the table, so call it whatever you'd call it out loud.

Pick the handful that matter: the page people land on, the page they buy from, the page they
use to reach you. Five or six is plenty. Twelve is the most one run will get through.

**The two lines below are examples on a placeholder address.** Delete them and write your
own. Until you do, the routine has nothing real to open, so it will say so rather than check
made-up pages.

- Example home page — https://example.com/
- Example pricing page — https://example.com/pricing
