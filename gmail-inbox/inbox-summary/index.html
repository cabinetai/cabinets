1Connect Gmail

Your agent reads mail through the Gmail connector. Until that is connected it has nothing to read and every run will say so rather than inventing a summary.

  1. Open Connectors in the sidebar.
  2. Find Gmail and press Connect.
  3. Sign in with the Google account whose inbox you want summarised.
  4. Approve read access. Cabinet stores the token on this machine only.
Open Connectors
2Set when it runs

The routine that fills this page lives on the agent’s Schedule tab. Open the agent, then Schedule → Morning Inbox Summary.

  • Change the time, or switch it off — the strip at the top of this page reads the real job file, so it always shows the truth.
  • Press ▷ next to the routine to run it once, right now.
  • Each run writes one dated file into daily-summaries/. Nothing is overwritten, so yesterday stays readable.
3Where the answers get saved

Ask for something new and the agent writes it into this cabinet as a page you can reopen, search and hand to another agent.

  • daily-summaries/ — one file per run of the morning routine.
  • subscriptions.md, waiting-on-me.md, … — whatever you ask for, named after what it holds.
  • This page reads daily-summaries/ directly, so a new run shows up on reload.

Ask it to “update the webapp” and it can edit this page too — it is a plain file in the cabinet, same as everything else.

4What it can and can’t do
  • Reads your mail, writes pages, and drafts replies.
  • Drafts only. A reply it writes lands in your Gmail drafts — you press send.
  • Local. Mail is read on this machine, into files you own.
  • If it cannot reach Gmail it says so and keeps the previous result rather than filling the gap with a guess.
