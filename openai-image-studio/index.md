# OpenAI Image Studio

Describe a picture and get a real image file in your cabinet.

## What you get

A page with a box on it. Write what you want to see, press Send, and about a minute
later the picture is sitting in this cabinet as a real file you can drag anywhere.
Every picture keeps the words that made it in a small text file beside it, so you can
run it again with one thing changed.

It also makes a fresh set of four every Monday morning without being asked, so there
is always something there.

## How to look at it

Open the **Studio** app in this cabinet. It comes pre-filled with example pictures so
the page is not empty — it says on the page that they are examples. Your first real
set replaces them.

## Before it can make real pictures

Connect OpenAI Image in Cabinet's integrations screen. You get an API key from
OpenAI's platform — sign in, create a key under API keys, paste it into Cabinet.
Two minutes, once. Cabinet keeps the key in a locked file on your own machine.

## What's inside

- **Image Maker** — the one agent. Turns your words into a picture.
- **Weekly Image Set** — the one routine. Runs Monday at 09:00.
- **Studio** — the one page. Write a description, watch it appear.
