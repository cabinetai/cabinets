# Bright Data Web Search

Ask the live web a question and keep the answer.

## What you get

A page with a box on it. Write a question, press Send, and the answer comes back as
a short table — each row a finding, why it matters to you, and the exact page it
came from. Every source is a URL you can click through to and check for yourself.

It also answers a standing question every Monday morning without being asked, so
there is always something there.

## How to look at it

Open the **Search** app in this cabinet. It comes pre-filled with a made-up example
so you can see the shape of it straight away — the page says clearly that the
answer is fake. Your first real answer takes its place.

## Before it can search the real web

Bright Data is one of the easy ones. Sign up at Bright Data's site, copy the API
key it gives you, and paste it into Cabinet's integrations screen. Two minutes,
once. Cabinet keeps the key in a locked file on your own machine — it goes nowhere
else.

## What's inside

- **Web Reader** — the one agent. Searches the web, writes the answer with sources.
- **Weekly Bright Data Search** — the one routine. Runs Monday at 08:00.
- **Search** — the one page. Ask a question, watch the answer appear.
